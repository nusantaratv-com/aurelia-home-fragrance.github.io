# AURELIA — Home Fragrance

A premium-inspired static ecommerce storefront for candles, diffusers, room fragrance, oils, wax melts, accessories and gift sets.

## What changed from the reference
- Rebuilt the pharmacy concept into the AURELIA home-fragrance brand.
- Replaced pharmacy navigation, copy and workflows with fragrance shopping journeys.
- Added AURELIA branding, warm neutral palette, botanical/gold accents and editorial typography.
- Added 16 distinct product assets and 8 collection assets.
- Added working client-side bag, save buttons, category filters, mobile navigation and contact form demo.
- Added dedicated category pages plus Our Story, Contact, Shipping & Returns, FAQ, Privacy and 404 pages.
- Included local assets so the site does not depend on pharmacy images from the reference ZIP.

Product visuals are stored locally in `assets/images/products/`. Each product has its own file and a consistent 800×800 composition so cards remain aligned and products are not aggressively cropped.
