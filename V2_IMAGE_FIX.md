# AURELIA V2 — Image Text Fix

## What changed

- Removed embedded text from the hero SVG.
- Removed embedded text from category and product SVG artwork where present.
- Hero copy remains as real HTML text, so it can be positioned independently and remains responsive.
- Product/category names remain in the website cards instead of being baked into image files.
- All visual assets remain local to the project.

## Visual rule

Images should contain the product or visual scene only. Titles, prices, buttons and promotional copy belong to the HTML interface, not inside product photography or artwork.
